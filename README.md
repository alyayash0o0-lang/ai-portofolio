# AI Engineer Portfolio

## Overview
This repository serves as my AI Engineer portfolio, showcasing projects that focus on building practical, explainable, and usable AI systems.

Rather than training models from scratch, my work emphasizes:
- applying AI to solve real problems
- combining rule-based logic with AI capabilities
- designing AI systems that are structured, explainable, and deployable

- AI-powered productivity tools
